# 🎮 Interaction Gallery by Team 5
### live link: https://abida3564.github.io/Interaction-Gallery/

An interactive gallery of four mini-games, each exploring a different input method: keyboard, mouse, microphone, and camera-based hand gestures. Built with vanilla HTML/CSS/JS, WebGL/Canvas, and [MediaPipe Hands](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker) for real-time gesture tracking.

## 🖼️ Overview
The gallery presents four "rooms," each a self-contained interaction study demonstrating a **signal → threshold → cooldown → feedback** pipeline.

| Room | Title | Input | Description |
|------|-------|-------|--------------|
| 🌊 01 | **Save the River** | Mouse / 3D game | Sort waste into the correct bins before it pollutes the river. |
| 🏎️ 02 | **Highway Dodge** | Keyboard (WASD / Arrows) | Dodge rival cars on a winding highway and collect stars — more than 10 hits ends the run. |
| 🎈 03 | **Balloon Fly** | Microphone + Mouse | Blow into the mic (or hold Space) to lift letter balloons and pop them **in order** to spell the shown word. |
| ✌️ 04 | **Gesture Mirror** | Camera + Hand Gestures | Show a hand sign (✌️ victory, 👍 like, 👎 dislike, or two open hands for a high five) and the system reads it and answers back with a matching reaction. |

## ✨ Features
- 🎠 Carousel-style gallery home with keyboard navigation (`←` `→` `Enter`)
- 🎚️ Difficulty selector (Easy / Medium / Hard) in **Highway Dodge**
- 🔤 Word-spelling mechanic with mic-controlled lift in **Balloon Fly**
- ✋ Real-time hand-landmark tracking via MediaPipe in **Gesture Mirror**
- 🏆 Worldwide scoreboard — post your score and compete on a shared leaderboard per room
- 👍❤️👎 Live reaction voting on every game card, with worldwide vote sync
- ⭐ Community rating display per room (average score + vote count)
- 👑 "Top scorer" badge shown live on each gallery card
- 🔊 Lightweight synthesized sound effects — no audio assets required
- ♿ Accessible focus states and keyboard support throughout
